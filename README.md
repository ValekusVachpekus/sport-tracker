# Sport Tracker

Личный журнал силовых тренировок. В нём можно составить недельную программу, записать подходы и сравнить результаты по упражнениям. Начатая тренировка сохраняется в браузере: после восстановления связи и открытия сайта завершённая запись отправляется в Supabase.

## Подключение Supabase

1. Создать проект на тарифе Free и выполнить файл [миграции](supabase/migrations/202611200001_journal.sql) один раз в **SQL Editor**.
2. В **Authentication → Users** создать своего пользователя с email и паролем и подтвердить его через панель. В **Authentication → Sign In / Providers** оставить включённым вход по email, отключить самостоятельную регистрацию и анонимный вход. Пароль задаётся в панели Supabase.
3. Скопировать **Project URL** и ключ **Publishable key** с префиксом `sb_publishable_`. Политики RLS ограничивают доступ к программе и журналу ID пользователя. Ключ администратора и пароль пользователя держать вне репозитория.

## Запуск и публикация

Для локального запуска нужны Node.js 22.12+ и npm. Скопировать `.env.example` в `.env.local` и заполнить значения.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Для публикации создать публичный репозиторий `Sport-Tracker` с веткой `main`. В **Settings → Secrets and variables → Actions → Variables** добавить `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY`. В **Settings → Pages → Source** выбрать **GitHub Actions**. После загрузки исходников запустить workflow **GitHub Pages** или открыть запуск от коммита. Ссылка на опубликованный сайт появится в окружении `github-pages`.

Офлайн-режим проверяется на собранном приложении через `npm run preview` или на GitHub Pages. Первый вход и загрузка сайта требуют связи. Если Supabase Free приостановит проект из-за низкой активности, его можно восстановить в панели. После восстановления журнал отправит ожидающие записи при открытии или повторе синхронизации.

## Питание

На следующем этапе добавить дневник калорий и БЖУ, базовый каталог и свои продукты с показателями на 100 г. Запоминать последнюю порцию и дать возможность повторить запись из недавних. Поиск по штрихкоду оценить после проверки покрытия продуктов, которыми пользуешься.
